# 数据治理中心 MVP PRD v0.1

## 1. 项目定位

建设一个面向 AI Agent 的企业数据语义治理平台。

第一阶段目标：

将 DataWorks MaxCompute 中的物理数据资产，治理成为 AI 可理解的语义资产。

核心链路：

    DataWorks ODPS
        ↓
    Metadata同步
        ↓
    数据资产管理
        ↓
    人工选择表+字段
        ↓
    AI生成语义
        ↓
    人工审核
        ↓
    Semantic Package
        ↓
    未来Agent消费

------------------------------------------------------------------------

# 2. 第一阶段范围

## 包含

-   DataWorks ODPS 元数据接入
-   数据源管理
-   Project管理
-   表资产管理
-   字段管理
-   单表治理任务
-   AI字段语义生成
-   人工审核发布
-   Semantic Package生成

## 不包含

-   Agent查询
-   Text2SQL
-   PI SDK集成
-   RAG
-   Embedding
-   Join关系治理
-   血缘
-   数据质量
-   权限执行
-   完整指标中心

------------------------------------------------------------------------

# 3. 核心设计原则

## 3.1 物理资产与语义资产分离

物理层：

    meta_table
    meta_column

记录数据库真实结构。

语义层：

    table_semantic
    column_semantic

记录业务理解。

------------------------------------------------------------------------

## 3.2 AI建议与正式结果分离

AI生成：

    ai_table_suggestion
    ai_column_suggestion

人工确认后：

    table_semantic
    column_semantic

AI不能直接覆盖正式结果。

------------------------------------------------------------------------

## 3.3 表作为治理主体

规则：

-   一张表一个治理资产
-   字段可以增量治理
-   治理范围由人工选择

流程：

    选择表
     ↓
    选择字段
     ↓
    AI治理
     ↓
    人工审核
     ↓
    发布

------------------------------------------------------------------------

# 4. 功能模块

## 数据资产管理

### 数据源

支持：

-   MaxCompute ODPS
-   数据源配置
-   连接测试

### Project

展示：

-   ODPS Project
-   Project下表

### 表资产

展示：

-   表名
-   Project
-   类型
-   字段数量
-   更新时间
-   治理状态

### 字段

展示：

-   字段名
-   类型
-   注释
-   是否分区字段

------------------------------------------------------------------------

# 治理任务

## 创建治理任务

入口：

表详情 → 字段选择

用户选择字段后创建任务。

------------------------------------------------------------------------

## AI治理

输入：

-   表信息
-   字段Schema
-   历史治理结果
-   治理规则

输出：

表：

-   业务名称
-   描述
-   粒度
-   使用场景

字段：

-   中文名称
-   字段说明
-   类型
-   聚合方式
-   单位
-   使用规则
-   置信度

------------------------------------------------------------------------

# 审核发布

人工：

-   查看AI结果
-   修改内容
-   发布

发布后：

生成：

    table_semantic
    column_semantic
    semantic_package

------------------------------------------------------------------------
