# 数据治理中心 数据模型与开发计划

# 一、核心数据模型

## 物理层

### data_source

数据源。

### meta_project

ODPS Project。

### meta_table

物理表。

### meta_column

物理字段。

------------------------------------------------------------------------

## 治理层

### governance_task

一次治理任务。

记录：

-   表
-   选择字段
-   状态

### ai_table_suggestion

AI生成表建议。

### ai_column_suggestion

AI生成字段建议。

------------------------------------------------------------------------

## 语义层

### table_semantic

正式表语义。

包含：

-   业务名称
-   描述
-   数据粒度
-   使用场景

### column_semantic

正式字段语义。

包含：

-   中文名称
-   字段类型
-   聚合方式
-   业务说明

------------------------------------------------------------------------

## 输出层

### semantic_package

给未来Agent使用。

------------------------------------------------------------------------

## 规则层

### governance_rule

AI治理规则。

例如：

字段包含：

    amount
    amt

建议：

    Metric
    SUM

------------------------------------------------------------------------

# 二、开发里程碑

# Milestone 1 项目基础

任务：

-   初始化Next.js
-   初始化NestJS
-   PostgreSQL配置
-   Prisma配置
-   基础目录

验收：

项目启动成功。

------------------------------------------------------------------------

# Milestone 2 DataWorks接入

任务：

-   ODPS连接
-   Project同步
-   Table同步
-   Column同步
-   数据资产页面

验收：

可以查看ODPS表和字段。

------------------------------------------------------------------------

# Milestone 3 治理流程

任务：

-   表详情
-   字段选择
-   创建治理任务
-   任务列表

验收：

可以发起治理。

------------------------------------------------------------------------

# Milestone 4 AI治理

任务：

-   Context组装
-   Prompt模板
-   LLM调用
-   JSON解析
-   保存AI建议

验收：

生成字段语义建议。

------------------------------------------------------------------------

# Milestone 5 审核发布

任务：

-   AI审核页面
-   修改结果
-   发布
-   保存正式语义

验收：

产生table_semantic和column_semantic。

------------------------------------------------------------------------

# Milestone 6 Semantic Package

任务：

-   Package生成
-   JSON展示
-   查询接口

验收：

生成Agent可消费结构。

------------------------------------------------------------------------

# Codex执行要求

每个Milestone：

1.  先阅读设计文档。
2.  只实现当前阶段。
3.  完成后输出：
    -   完成内容
    -   测试结果
    -   下一步计划。

禁止一次性扩展未规划功能。
