# Milestone 2 DataWorks接入

## 1. 目标

完成 Eureka Atlas 与 DataWorks MaxCompute（ODPS）的基础元数据接入。

目标：

将 DataWorks 中的数据资产同步到治理平台，使用户可以查看 ODPS
Project、数据表和字段信息。

流程：

    DataWorks ODPS
            ↓
    Metadata同步服务
            ↓
    PostgreSQL元数据存储
            ↓
    数据资产页面展示

本阶段只同步元数据，不读取业务数据。

------------------------------------------------------------------------

# 2. 本阶段范围

## 包含

-   ODPS 数据源连接
-   Project同步
-   Table同步
-   Column同步

-   数据资产页面

## 不包含

# 3. 数据模型

使用：

    data_source

    meta_project

    meta_table

    meta_column

职责：

## data_source

保存 MaxCompute 数据源配置。

## meta_project

保存 ODPS Project 信息。

## meta_table

保存物理表信息。

## meta_column

保存物理字段信息。

------------------------------------------------------------------------

# 4. 功能设计

## 4.1 ODPS连接

目标：

配置并验证 MaxCompute 数据源。

支持：

-   数据源名称
-   Region
-   AccessKey
-   SecretKey

验收：

-   可以保存数据源
-   可以测试连接状态

------------------------------------------------------------------------

## 4.2 Project同步

流程：

    数据源
     ↓
    调用ODPS接口
     ↓
    获取Project
     ↓
    保存meta_project

保存：

-   Project名称
-   描述
-   数据源关联

验收：

可以查看：

    paiwo_sales
    paiwo_supply

------------------------------------------------------------------------

## 4.3 Table同步

同步：

-   表名
-   表类型
-   表注释
-   更新时间

保存：

    meta_table

规则：

新增表：

创建记录。

已有表：

更新信息。

删除表：

标记DEPRECATED，不物理删除。

------------------------------------------------------------------------

## 4.4 Column同步

同步：

-   字段名
-   数据类型
-   字段注释
-   字段顺序
-   是否分区字段

保存：

    meta_column

删除字段：

标记DEPRECATED。

------------------------------------------------------------------------

# 5. 页面设计

## 数据源

路径：

    /assets/sources

功能：

-   查看数据源
-   新增数据源
-   测试连接

------------------------------------------------------------------------

## 数据资产列表

路径：

    /assets/tables

展示：

-   表名
-   Project
-   字段数量
-   更新时间
-   治理状态

------------------------------------------------------------------------

## 表详情

路径：

    /assets/tables/:id

展示：

概览：

-   表名
-   Project
-   更新时间

字段：

-   字段名
-   类型
-   注释
-   分区字段
