# Milestone 3 治理流程

## 1. 目标

建立 Eureka Atlas 单表治理流程。

本阶段目标：

让用户可以从数据资产中选择一张表，并选择需要治理的字段，创建治理任务。

流程：

    ODPS数据资产
        ↓
    表详情
        ↓
    字段选择
        ↓
    创建治理任务
        ↓
    任务记录

本阶段不涉及 AI。

------------------------------------------------------------------------

# 2. 本阶段范围

## 包含

-   表详情页面
-   字段展示
-   字段选择
-   创建治理任务
-   治理任务列表
-   治理任务详情基础页

## 不包含

-   AI生成语义
-   Prompt
-   LLM调用
-   AI Suggestion
-   审核发布
-   Semantic Package

------------------------------------------------------------------------

# 3. 数据模型

新增使用：

    governance_task

职责：

记录一次治理任务。

字段：

  字段               说明
  ------------------ ----------------
  id                 任务ID
  table_id           治理表ID
  selected_columns   选择字段(JSON)
  status             任务状态
  created_by         创建人
  created_at         创建时间
  updated_at         更新时间

状态：

    PENDING
    待处理

    PROCESSING
    处理中

    REVIEWING
    待审核

    COMPLETED
    完成

创建任务默认：

    PENDING

------------------------------------------------------------------------

# 4. 页面设计

## 4.1 表详情页面

路径：

    /assets/tables/:id

展示：

-   表名
-   Project
-   类型
-   字段数量
-   更新时间

Tabs：

    概览
    字段

------------------------------------------------------------------------

## 4.2 字段选择

目标：

人工选择需要治理字段。

原则：

字段选择由人工完成，不由 AI 决定。

交互：

    ☑ stat_date

    ☑ shop_project

    ☑ gmv

底部：

    已选择3个字段

    [开始治理]

------------------------------------------------------------------------

## 4.3 创建治理任务

点击：

    开始治理

创建：

    governance_task

------------------------------------------------------------------------

## 4.4 治理任务列表

路径：

    /governance/tasks

展示：

-   任务
-   表
-   字段数量
-   状态
-   创建时间

------------------------------------------------------------------------

## 4.5 治理任务详情

路径：

    /governance/tasks/:id

第一阶段展示：

-   表信息
-   选择字段
-   当前状态

不实现 AI 内容。

------------------------------------------------------------------------

# 5. API设计

创建任务：

    POST /api/governance/tasks

请求：

``` json
{
  "tableId":1001,
  "columns":[101,102,103]
}
```

任务列表：

    GET /api/governance/tasks

任务详情：

    GET /api/governance/tasks/:id
