# Milestone 4 AI治理

## 1. 目标

在 Milestone 3 治理流程基础上，引入 AI 辅助治理能力。

本阶段目标：

> 根据治理任务中选择的表和字段，生成字段语义建议，并保存为 AI 建议结果。

流程：

    治理任务
        ↓
    读取表结构
        ↓
    Context组装
        ↓
    Prompt生成
        ↓
    调用LLM
        ↓
    JSON解析
        ↓
    保存AI建议

本阶段只生成 AI 建议，不进行人工审核和发布。

# 4. AI治理流程

## 4.1 获取治理任务

读取：

    governance_task

获取：

-   table_id
-   selected_columns

------------------------------------------------------------------------

## 4.2 Context组装

创建：

    GovernanceContextService

负责将治理信息转换成 AI 输入。

Context包含：

### 表信息

来源：

    meta_table

包括：

-   Project
-   表名
-   表注释
-   表类型

### 字段信息

来源：

    meta_column

包括：

-   字段名
-   类型
-   注释
-   分区信息

### 历史语义参考

来源：

    column_semantic

用于参考已确认业务定义。

### 治理规则

来源：

    governance_rule

用于辅助判断。

------------------------------------------------------------------------

# 5. Prompt设计

角色：

    你是一名企业数据治理专家。

任务：

    根据数据库表结构和已有业务知识，
    为字段生成业务语义定义。

要求：

必须返回 JSON。

禁止：

-   Markdown
-   额外说明文字

------------------------------------------------------------------------

# 6. AI输出格式

## 表建议

保存：

    ai_table_suggestion

示例：

``` json
{
 "business_name":"店铺销售日报",
 "description":"用于分析店铺每日销售经营情况",
 "grain":"日期+店铺"
}
```

------------------------------------------------------------------------

## 字段建议

保存：

    ai_column_suggestion

示例：

``` json
{
 "column_name":"gmv_deduct_emp",
 "business_name":"销售额",
 "semantic_type":"METRIC",
 "description":"扣除员工内购后的销售金额",
 "aggregation":"SUM",
 "unit":"元",
 "usage_rule":"用于销售规模统计",
 "confidence":0.95,
 "reason":"根据字段名称和历史语义判断"
}
```
