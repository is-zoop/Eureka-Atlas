# Milestone 6 Semantic Package

## 1. 目标

在 Milestone 5 正式语义资产基础上，生成面向未来 Agent 使用的 Semantic
Package。

本阶段目标：

> 将已经审核通过的表语义和字段语义，转换为 AI 可消费的数据语义结构。

流程：

    table_semantic

    +

    column_semantic

    ↓

    Semantic Package

    ↓

    Agent消费接口

------------------------------------------------------------------------

# 2. 本阶段范围

## 包含

-   Semantic Package生成
-   Package存储
-   JSON展示
-   Package查询接口

------------------------------------------------------------------------

## 不包含

-   Agent调用
-   PI SDK集成
-   RAG
-   向量检索
-   SQL生成
-   数据查询执行

------------------------------------------------------------------------

# 3. Semantic Package定位

Semantic Package不是数据库结构复制。

它是：

> 面向AI理解的数据语义描述。

包含：

-   表是什么
-   字段代表什么
-   字段如何使用
-   查询时需要注意什么

------------------------------------------------------------------------

# 4. Package生成流程

触发方式：

治理任务发布成功后。

流程：

    column_semantic

    table_semantic

            ↓

    Package Builder

            ↓

    semantic_package

            ↓

    Agent读取

------------------------------------------------------------------------

# 5. 数据模型

使用：

    semantic_package

------------------------------------------------------------------------

## semantic_package职责

保存：

-   表语义结构
-   字段语义结构
-   AI消费JSON

------------------------------------------------------------------------

建议字段：

  字段         说明
  ------------ ----------
  id           主键
  table_id     对应表
  content      JSON内容
  created_at   创建时间
  updated_at   更新时间

------------------------------------------------------------------------

# 6. Package结构设计

第一版结构：

``` json
{
  "table": {
    "name": "v_dws_shop_sales_daily",
    "business_name": "店铺销售日报",
    "description": "用于分析店铺每日销售经营情况",
    "grain": "日期+店铺"
  },

  "fields": [
    {
      "column": "gmv_deduct_emp",
      "name": "销售额",
      "type": "METRIC",
      "description": "扣除员工内购后的销售金额",
      "aggregation": "SUM",
      "unit": "元"
    }
  ],

  "rules": [
    "销售额默认使用gmv_deduct_emp"
  ]
}
```

------------------------------------------------------------------------

-   使用规则

    读取语义资产

    ↓

    构建JSON

    保存semantic_package

## 查询Package
