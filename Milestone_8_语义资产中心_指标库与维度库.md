# Milestone 8 语义资产中心：指标库与维度库

## 1. 目标

建设 Eureka Atlas 语义资产聚合能力。

本阶段目标：

将治理发布后的指标和维度自动沉淀为统一语义目录，方便业务人员查找，同时为未来
Agent 提供稳定语义入口。

核心原则：

> 指标库和维度库不是生产入口，而是治理结果的消费入口。

------------------------------------------------------------------------

# 2. 核心流程

    数据资产

    ↓

    字段治理

    ↓

    ColumnSemantic / SemanticMetric

    ↓

    发布

    ↓

    指标库 / 维度库

    ↓

    业务查询

------------------------------------------------------------------------

# 3. 设计原则

## 3.1 不新增指标创建入口

禁止：

-   在指标库手动创建指标；
-   创建第二套指标定义流程；
-   绕过治理审核。

指标唯一来源：

    治理工作台发布结果

------------------------------------------------------------------------

## 3.2 发布驱动沉淀

发布流程：

    Governance Publish

    ↓

    table_semantic

    column_semantic

    ↓

    Metric/Dimension Sync

    ↓

    Catalog

------------------------------------------------------------------------

# 4. 指标库

路径：

    /semantic/metrics

## 4.1 指标来源

来源：

    ColumnSemantic
    semanticType = METRIC

    SemanticMetric

------------------------------------------------------------------------

## 4.2 同名指标归并

示例：

表A：

    dws_shop_sales_daily

    pay_amt

    ↓

    支付金额

表B：

    ads_trade_summary

    trade_amt

    ↓

    支付金额

发布时：

不创建两个指标。

形成：

    支付金额

    ├── dws_shop_sales_daily.pay_amt

    └── ads_trade_summary.trade_amt

------------------------------------------------------------------------

## 4.3 指标列表

展示：

  指标名称   类型       说明                     关联表数量   状态
  ---------- ---------- ------------------------ ------------ --------
  支付金额   原子指标   用户实际支付金额         12           已发布
  退款率     派生指标   退款金额占支付金额比例   5            已发布

------------------------------------------------------------------------

## 4.4 指标详情

展示：

基础信息：

-   指标名称
-   指标说明
-   指标类型
-   单位
-   聚合方式

来源：

展示所有绑定表：

    支付金额

    ├── dws_shop_sales_daily
    │   字段: pay_amt

    └── ads_trade_summary
        字段: trade_amt

点击表：

跳转：

    /assets/tables/:id

------------------------------------------------------------------------

# 9. 人工维护范围

允许补充：

-   指标别名
-   业务分类
-   负责人
-   使用说明

不允许修改：

-   来源字段
-   聚合逻辑
-   计算公式

这些属于治理结果。

------------------------------------------------------------------------

# 10. 验收标准

## 指标库

-   发布后自动进入指标库；
-   同名指标自动归并；
-   一个指标支持多个表；
-   可以查看指标说明；
-   可以查看来源字段；
-   可以跳转表详情。

## 维度库

-   发布后自动进入维度库；
-   同名维度自动归并；
-   可以查看来源字段；
-   可以跳转表详情。

------------------------------------------------------------------------

-   引入 Agent；
-   引入 RAG。

> 将治理产生的语义资产沉淀成企业统一指标库和维度库。
