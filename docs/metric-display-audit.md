# 指标单位展示约定

用户已明确：**正式语义中的unit就是展示转换规则。** 不需要维护百分比尺度或显示精度字段。先前引入的displayFormat/display_format、百分比尺度下拉、精度输入及未确认提示均已移除，不能再按旧文档要求补配置。

- `%`：原值×100，默认两位并显示百分号。
- `万元`：原值÷10000，默认两位，表头标注万元。
- `亿元`：原值÷100000000，默认两位；其他万/亿数量单位按同样倍率。
- `‰`：原值×1000。`千元`、`百万元`等按对应数量级换算。
- 普通单位不改倍率；未填写单位不从指标名称猜测。物理单位千克/千瓦不自动缩放。

已复现截图中的推广点击率与推广加购率：正式unit都是%，原值分别显示为4.73%、15.90%。只改显示，不改公式或原始结果；presentation已完成转换，模型不得再乘100。

正式单位即约定。某指标的unit若录错，应按原治理流程修正单位；格式化器不根据指标名称擅自覆盖。例如“客单价”如果被填成%，将按%展示，而不是自行猜成元。

部署共享格式库、API/Web及2.4.1插件后生效，不需要额外配置或为了单位转换重新发布全部语义。数据库清理迁移及验证边界见 [实现与部署](agent-query-quality-implementation.md)。
